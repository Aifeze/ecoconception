TP 05 : Optimisation du code

Thème : Algorithmique et sobriété • 7 langages au choix

Objectif

Réécrivez du code pour obtenir le même résultat avec moins de calculs ou moins de copies. Vous vérifierez chaque optimisation en comparant le travail effectué sur les mêmes données.

Prérequis et ressources

Il suffit de connaître les variables, opérateurs et tableaux d’un des langages du site. Le correcteur fonctionne dans le navigateur.

Exercices pratiques

  1. Choisissez un langage et un exercice.
  2. Repérez le travail inutile dans le code de départ.
  3. Écrivez une expression équivalente et validez-la pour afficher la comparaison.

Si les champs restent désactivés, le correcteur n’a pas pu se charger. Vérifiez que JavaScript est activé et rechargez la page.

Guide JavaScript

Remplacer des additions répétées

Calculez la somme des entiers de 1 à n. Quand n vaut 0, la somme vaut 0.

Code de départ

function somme(n) {
    let total = 0;
    for (let i = 1; i <= n; i++) total += i;
    return total;
}

La boucle additionne un nombre à chaque tour, même lorsqu’un calcul direct suffit.

Votre optimisation

Variable : n, un entier de 0 à 20 000.

Saisissez l’expression seule, sans fonction ni point-virgule.

Afficher un indice

Écrivez la suite dans les deux sens et additionnez les termes deux à deux. Quelle somme retrouve-t-on à chaque paire ?

Conclusion : interpréter les résultats

Pour chaque exercice terminé, relevez la différence avant et après, puis expliquez quel parcours, calcul ou tableau temporaire votre expression a évité.

Le correcteur évalue un sous-ensemble d’expressions du langage choisi. Il compte les opérations et les éléments temporaires sur les jeux de données de l’exercice. Un chronométrage ou une mesure de RAM demanderait une exécution native.

Le badge EcoIndex estime l’empreinte de la page à partir de la taille du DOM, du nombre de requêtes et du poids transféré.
